NYC Interactive WebGIS is a web-based GIS application designed to visualize and interact with geospatial data through an interactive map interface. The project uses Leaflet.js for client-side mapping and GeoServer to publish geospatial datasets as WMS services. GeoServer is containerized using Docker, while Cloudflare Tunnel provides external access to the locally hosted GIS services. The frontend is developed using HTML, CSS, and JavaScript and deployed through Netlify, with the source code maintained on GitHub.
